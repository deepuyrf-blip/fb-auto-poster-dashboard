# FB Auto Poster — Control Panel

Live dashboard: **https://deepuyrf-blip.github.io/fb-auto-poster-dashboard/**

Is page se aap apne bot (repo `fb-auto-poster`) ko manage kar sakte hain:
- **Status** — recent runs dekhna
- **Post karein** — topic par ya aaj ke trend par turant post
- **Theme** — kis topic par post ho aur kab tak

## Token chahiye

Page par ek **GitHub fine-grained token** daalna hoga (sirf `fb-auto-poster` repo ke liye):
- Permissions: **Actions: Read and write** + **Contents: Read and write**

Ye token sirf aapke browser mein (localStorage) save hota hai — kahin aur nahi bheja jaata.
Banane ka tarika: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.

## Note
Page public hai, par bina token ke kuch nahi kar sakta. Personal use ke liye hai.
